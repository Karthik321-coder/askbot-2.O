# Security Policy

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

### 🔒 Private Reporting
- **Email**: security@karthik.dev
- **Subject**: [SECURITY] AskBot Vulnerability Report

### 📝 What to Include
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### ⏰ Response Timeline
- **Initial Response**: Within 48 hours
- **Status Update**: Within 7 days
- **Fix Release**: Within 30 days (for confirmed vulnerabilities)

### 🛡️ Security Measures
- All data transmission uses HTTPS
- No sensitive data stored client-side
- Regular security audits
- Dependencies kept up-to-date

### 🏆 Recognition
Contributors who report valid security issues will be:
- Credited in our security acknowledgments
- Listed in our Hall of Fame (with permission)

Thank you for helping keep AskBot secure! 🔐
